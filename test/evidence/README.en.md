# Historical run evidence

The subdirectories document the dated, actual test runs.
On 2026-10-18, at explicit request, the project, class, path
and artifact names in the archived texts were editorially normalized to **phi-spaces**.

These files are therefore no longer unchanged raw logs. Measured values, failure patterns
and the acceptance limits of the time were not issued as new runs. Artifact hashes and signatures
they contain refer to the original bytes of the time, not
to newly generated bundles or editorially normalized JSON/text files.
The unedited versions remain available in the git history before this change.
