# Historische Laufnachweise

Die Unterverzeichnisse dokumentieren die jeweils datierten tatsächlichen Prüfläufe.
Am 18. Oktober 2026 wurden auf ausdrücklichen Wunsch die Projekt-, Klassen-, Pfad-
und Artefaktnamen in den archivierten Texten redaktionell auf **phi-spaces** normalisiert.

Diese Dateien sind deshalb keine unveränderten Rohlogs mehr. Messwerte, Fehlerbilder
und damalige Abnahmegrenzen wurden nicht als neue Läufe ausgegeben. Enthaltene
Artefakthashes und Signaturen beziehen sich auf die damaligen Originalbytes, nicht
auf neu erzeugte Bundles oder redaktionell normalisierte JSON-/Textdateien.
Die unbearbeiteten Fassungen bleiben im Git-Verlauf vor dieser Änderung auffindbar.
